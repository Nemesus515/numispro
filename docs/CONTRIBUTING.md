# Contributing

## Our Principles

1. Build for collectors.
2. Keep the interface simple.
3. Quality over quantity.
4. Every feature must solve a real problem.
5. Document every important decision.
6. Write clean and maintainable code.
7. Think long-term.

---

## Code Style

- TypeScript everywhere
- English for code and documentation
- Small commits
- Clear commit messages

---

## Git Workflow

main → stable

feature/* → new features

fix/* → bug fixes

---

## Pull Requests

Every feature should be reviewed before merging.

---

## Goal

Build the best platform for coin collectors.
