# 🪙 NumisPro
> Collect. Analyze. Share.
> The modern platform for numismatists and collectors.

## Что такое NumisPro?

NumisPro — это современная платформа для коллекционеров монет.

Наша цель — создать лучший цифровой помощник для нумизматов, объединив каталог монет, управление коллекцией, аналитику стоимости и сообщество коллекционеров в одном месте.

Мы не просто создаём каталог монет.

Мы создаём экосистему коллекционирования.

## 📚 Каталог монет

- Подробные карточки монет
- Разновидности
- История выпусков
- Технические характеристики
- Фотографии высокого качества

## 🪙 Моя коллекция

- Неограниченное количество коллекций
- Учёт каждого экземпляра

- Фотографии пользователей

- Достижения

# Почему NumisPro?

NumisPro создаётся коллекционерами для коллекционеров.

Наша задача — сделать сервис, который будет удобнее, быстрее и информативнее существующих решений.
